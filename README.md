# Delivery Rider Portal

The Delivery Rider Portal is a web-based system designed for managing rider delivery tasks. It allows riders to log in, view assigned deliveries, update delivery status, and monitor delivery history.

## System Integration

This system is integrated with the **Authentication System** for rider login and role-based access. Only users with the `rider` role can access the Delivery Rider Portal.

## Main Features

- Rider login authentication
- Rider dashboard
- View assigned deliveries
- Update delivery status
- View delivery history
- Role-based access for riders
- Prepared for future connection with order, notification, tracking, and analytics systems

## Technologies Used

- React.js
- Node.js
- Express.js
- MySQL
- JWT Authentication
